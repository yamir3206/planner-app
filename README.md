## 🗄️ دیتابیس

برنامه بدون هیچ تنظیماتی با **IndexedDB** (مرورگر) کار می‌کند و آفلاین است.

برای دیتابیس ابری:
- تنظیمات → دیتابیس → انتخاب نوع
- یا متغیر محیطی: `VITE_DATABASE_TYPE=supabase`

انواع:
- `auto` - هوشمند (پیش‌فرض)
- `indexeddb` - مرورگر آفلاین
- `localstorage` - ساده
- `supabase` - ابری
- `firebase` - گوگل
- `rest` - سرور شخصی
